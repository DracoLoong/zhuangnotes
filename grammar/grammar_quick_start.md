# 语法快速入门 RIENGJ HAG YIJFAZ

本文可以快速地了解壮语的语法结构和迅速构造句子，而不必陷入琐碎的语法细节。这虽非完整而系统的框架，但是有基础汉语语法知识的人能轻易地入门。

## 指称人和物——构造名词性短语

名词短语告诉我们所谈论的是甚么人或事物。名词短语可以做主语或者宾语。

壮语的名词性短语一般遵循如下语序：

> **数词 + 量词/区别词 + 中心词 + 修饰语（形容词）+ 修饰语（表示领属的名词）+ <定语从句> + 指示代词**

我们拿“猫”meuz为例，逐步修饰它：

- Meuz. （猫）
- Duz meuz. （猫）
  - ｛量词 + 猫｝
  - 壮语在名词前经常会加相应的量词，起到限定或者协调音节的作用。
- Duz meuz iq. （小猫）
  - ｛量词 + 猫 + 小｝
- Duz meuz neix. （这只猫）
  - ｛量词 + 猫 + 这｝
- Duz meuz iq neix.  （这只小猫）
  - ｛量词 + 猫 + 小 + 这｝
- Sam duz meuz iq neix.  （这三只小猫）
  - ｛三 + 量词 + 猫 + 小 + 这｝
- Sam duz meuz iq baihdoeng neix. （这三只东边的小猫）
  - ｛三 + 量词 + 猫 + 小 + 东边 + 这｝
- Sam duz meuz iq baihdoeng Nanzningz neix. （这三只南宁东边的小猫）
  - ｛三 + 量词 + 猫 + 小 + 东边 + 南宁 + 这｝
  
同样的，使用定语从句来逐步修饰它：

先看看中心语做主语的定语从句，这相当于用动宾词组在修饰中心语，这会造成不可避免的歧义，需要靠语境区分：

- Duz meuz gaemh nou. 
  - ｛量词 + 猫 + 抓 + 鼠｝
  - 这有两种解释：“猫抓老鼠”（一个完整的句子）或者“抓老鼠的猫”（一个中定词组）。因为壮语的主谓结构和中定结构是同形的。
- Duz meuz gaemh nou neix. 
  - ｛量词 + 猫 + 抓 + 鼠 + 这 ｝
  - 这句话有两种解释：“猫抓这老鼠”或者“这只抓老鼠的猫”
  
中心语做宾语的定语从句，相当于用主谓结构词组在修饰中心语，这一般不会造成歧义：

- Duz meuz gou haengj. （我喜欢的猫）
  - ｛量词 + 猫 + 我 + 喜欢｝
  - 这还可以理解为：这只猫我喜欢，相当于宾语提前做了话题。但是可以通过其他手段消解歧义，如下：
- Duz meuz gou haengj neix. （这只我喜欢的猫）
  - ｛量词 + 猫 + 我 + 喜欢 + 这｝
  - 这句话没有歧义，注意代词“这”的位置。试比较：Duz meuz neix gou haengj. （这只猫我喜欢）
- Duz meuz gou soj haengj. （我所喜欢的猫）
  -｛量词 + 猫 + 我 + 所 + 喜欢｝
  - soj 借自汉语“所”，一般只在极为正式的书面语中出现。
  
那么，可以造一个很长的名词性短语：
- Sam duz meuz ndaem iq baihdoeng Nanzningz gou haengj neix. （这三只我所喜欢的南宁东部的小黑猫）
  - ｛三 + 量词 + 猫 + 黑 + 小 + 东边 + 南宁 + 我 + 喜欢 +这｝


## 构造完整的句子——作谓语的动词和形容词

壮语的陈述句中，至少需要一个谓语才能构成完整的句子。动词和形容词都能做谓语。

- 动词作谓语：
   - Duzvaiz gwn nywj. （牛吃草。）
- 形容词作谓语：
  - Gwnz congz nyungqnyatnyat. （床上乱七八糟的。）
 
好了，我们把上述那个长长的的名词性短语，扩展成句子：

Sam duz meuz ndaem iq baihdoeng Nanzningz gou haengj neix gaemh nou. （这三只我所喜欢的南宁东部的小黑猫抓老鼠）


## 动作的过程和状态——动词的体

动词的体描述动作的过程，来指明这个动作是怎么发生的、处于什么状态（是刚开始、正在进行、已经完成、做完留下了影响，还是作为历史经历）

 - 完整体（动作已完成）
   - 表示动作行为的完成 ，使用 liux、 bae、ndaej。liux放在动词后面或者句末，bae、ndaej放在动词之后。
     - Gwn liux haeux. = Gwn haeux liux. （吃完饭）
     - Sik bae song mbaw ceij. （撕了两张纸。）
     - Doeg ndaej song bi saw. （读了两年书。）

- 完成体（动作发生并影响现在）
  - 表示动作行为的完成 ，并对现在有影响，使用  le 和 lo 。le 用于动词后，lo 用于句末。
    - De bae Yiednamz lo. （他去越南了。）
 
 - 经历体（动作发生过）
   - 使用 gvaq，表示动作、行为、发展变化已成过去 。一般放在末端 ，也可放在动词后。
     - Dingq gienh saeh neix gvaq. （听说过这件事）

 - 持续体（动作正在发生）
   - 使用 cingq，置于动词前
     - cingq naengh daengq （正坐着凳子）
   - 使用 dwk，置于动词或者动宾短语之后
     - naengh daengq dwk （正坐着凳子）

 - 起始体（表示动作的开始）
   - 使用 hwnjdaeuj，置于动词或动宾短语后
     - De byaij hwnjdaeuj lumj duz lingz. （他走起来像头熊。）
     - Mbwn laep le, de lau hwnjdaeuj. （天黑了，他害怕起来）
   - 使用 haicij，置于动词前
     -Mbwn laep le, de haicij lau. （天黑了，他开始害怕。）

 - 尝试体
   - 使用 动词的重叠形式，来表示短暂的尝试
     - yawjyawj （看一看）
	 - camcam （问一问）
   - 也可使用 动词重叠式 + yawj
     - cimzcimz yawj （尝尝看）
	 - ciengqciengq yawj （唱一唱）

 - 短时体
   - 使用 yaep 或者 yaepndeu，表示短暂或随意的动作
     - Ra dieg naengh yaep. （找地方坐一下）
  	 - Sousib yaepndeu ran mwngz. （收拾一下你的房间）
